###  EPMS — Enterprise Project Management System
A role-based platform supporting **capacity planning, sprint tracking, resource allocation, burndown analysis, and delivery monitoring**.

**Focus:** Full-stack development, resource management workflows, dashboards, and reporting.

###  EcoGifts — Sustainable Gift Marketplace
An e-commerce project focused on eco-friendly gifting, with **product personalization, AR previews, gift discovery, and sustainability features**.
